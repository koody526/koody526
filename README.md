# 구대연

게임의 동작을 구현하는 것에서 멈추지 않고, **어떻게 실패하는지 재현하고 설명하는 과정**에 관심이 있는 Game QA / Software QA 지원자입니다.

- Unity 게임의 WebGL 전환 및 Firebase 연동 이슈 분석
- 테스트 케이스, 버그 리포트, 회귀 테스트 문서화
- Unity/C#, Vanilla JavaScript, Python/Pygame, C 프로젝트 경험

## 현재 정리 중인 대표 작업

- **ONE-TAP** — Unity 원터치 회피 게임과 WebGL/Firebase QA 사례
- **NEON SYNC** — 상태·재고·잠금 규칙이 있는 Vanilla JS 스마트 자판기
- **Pygame Snake OOP** — 충돌, 입력 제한, WIN 상태를 다루는 객체지향 게임
- **Game QA Case Study** — 재현 가능한 버그 리포트와 테스트 설계

전체 프로젝트와 QA 문서는 [Portfolio Hub](https://github.com/koody526/portfolio)와 [Game QA Case Study](https://github.com/koody526/game-qa-case-study)에서 확인할 수 있습니다.
